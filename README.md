# 个人训练助手

一个专为跑步训练、力量训练和减脂管理设计的综合训练管理应用。

![应用截图](https://img.shields.io/badge/React-18-blue) ![Vite](https://img.shields.io/badge/Vite-5-purple) ![License](https://img.shields.io/badge/license-MIT-green)

## 功能特点

### 🏃 跑步训练模块
- **配速区间计算**：根据半马PB自动计算训练配速区间
- **多种训练类型**：轻松跑、节奏跑、间歇跑、长距离跑、恢复跑
- **详细记录**：距离、时间、配速、心率、RPE等
- **训练历史**：查看所有跑步记录和趋势

### 🏋️ 力量训练模块
- **训练分类**：上肢推、上肢拉、下肢、核心、全身
- **动作库**：内置常见力量训练动作
- **自动生成**：根据训练类型自动生成训练计划
- **训练记录**：记录组数、重量、RPE等

### 📊 身体数据追踪
- **每日记录**：体重、体脂率、腰围、睡眠、疲劳感
- **趋势分析**：7日移动平均、体重变化趋势
- **可视化图表**：直观展示体重变化曲线
- **智能建议**：根据减重速度提供调整建议

### 📅 智能训练计划
- **自动生成**：基于用户配置和疲劳状态自动生成周计划
- **智能排课**：避免高强度跑步和腿部训练冲突
- **动态调整**：根据疲劳状态自动降低训练强度
- **科学恢复**：合理安排休息日和恢复训练

### 📈 周总结分析
- **训练统计**：本周跑量、训练次数、完成度
- **对比分析**：与上周数据对比
- **体重趋势**：周变化分析和建议
- **下周建议**：基于当前状态提供训练建议

### ⚙️ 个性化设置
- **个人信息**：身高、体重、目标体重等
- **训练目标**：减脂、维持、提升等不同目标
- **训练频率**：自定义每周跑步和力量训练次数
- **营养建议**：根据体重计算蛋白质和热量需求

## 技术栈

- **前端框架**：React 18
- **构建工具**：Vite
- **图表库**：Recharts
- **日期处理**：date-fns

## 使用说明

### 首次使用

1. **配置个人信息**：
   - 点击底部"设置"按钮
   - 填写身高、体重、目标体重等信息
   - 输入半马最好成绩（用于计算配速区间）
   - 设置每周训练天数

2. **查看训练计划**：
   - 点击"计划"查看本周自动生成的训练计划
   - 计划会根据疲劳状态自动调整

3. **记录训练**：
   - **跑步**：点击"跑步"添加跑步记录
   - **力量**：点击"力量"添加力量训练记录

4. **记录身体数据**：
   - 点击"数据"每天记录体重、体脂等数据
   - 查看体重变化趋势图和分析建议

5. **查看总结**：
   - 点击"总结"查看本周训练统计和下周建议

### 训练计划说明

系统会基于以下原则自动生成训练计划：

- **周一**：上肢推 + 轻松跑
- **周二**：间歇跑训练（高强度）
- **周三**：下肢力量（中等强度）
- **周四**：轻松跑
- **周五**：上肢拉 + 核心
- **周六**：长距离慢跑
- **周日**：休息或主动恢复

计划会根据以下因素自动调整：
- 疲劳状态（RPE > 8）
- 睡眠时长（< 6小时）
- 训练频率设置
- 上周训练量

### 配速区间参考

基于你的半马成绩，系统会计算：
- **轻松跑**：比半马配速慢25-40%
- **节奏跑**：接近半马配速（乳酸阈值）
- **间歇跑**：5K-10K比赛配速
- **长距离跑**：马拉松配速
- **恢复跑**：非常轻松的配速

### 减脂管理建议

- **理想减重速度**：每周0.3-1%体重
- **过快**：超过1%/周，可能影响训练表现
- **停滞**：连续2周无变化，需调整饮食或训练
- **蛋白质**：1.6-2.2g/kg体重/天
- **热量**：28-32 kcal/kg体重/天

## 数据说明

### 数据存储

所有数据保存在浏览器的 LocalStorage 中，包括：
- 用户配置信息
- 跑步训练记录
- 力量训练记录
- 身体数据记录

**注意**：
- 数据仅保存在本地浏览器，不会上传到服务器
- 清除浏览器数据会导致记录丢失
- 建议定期导出备份（功能待开发）

- 删除示例数据，从头开始记录
- 在示例数据基础上继续添加

## 核心功能实现

### 配速计算
基于 Jack Daniels 训练理论，根据半马成绩计算各训练区间配速。

### 疲劳管理
综合考虑：
- 最近3次训练的RPE平均值
- 睡眠时长
- 主观疲劳感

### 训练计划生成
- 避免高强度跑步和腿部力量训练在连续日
- 每周至少1天完全休息
- 根据疲劳状态自动降低强度

### 体重趋势分析
- 计算7日移动平均减少日常波动影响
- 分析周变化率判断减重速度
- 提供科学的调整建议

## 注意事项

1. **训练安全**：
   - 如感到不适，立即停止训练
   - 疲劳过度时请休息
   - 本应用仅供参考，不能替代专业教练指导

2. **数据准确性**：
   - 配速计算基于理论模型，实际情况因人而异
   - 营养建议为一般性建议，个体差异较大
   - 建议结合专业营养师和教练的指导

3. **健康警告**：
   - 如有心血管疾病、关节问题等，请咨询医生
   - 减重速度过快可能影响健康
   - 充足睡眠和营养对训练至关重要
